# 구름 정원 3D(Spline) 제작 가이드

인사이트 맨 위 구름 정원을 Spline 3D 장면으로 바꾸기 위한 디자이너·개발 약속이다. 앱은 정원 상태를 **Spline 변수**로 넣어 주고, 장면은 그 변수에 맞춰 모습을 바꾼다. 장면이 없거나 불러오지 못하면 지금의 2D 그림이 그대로 보인다.

## 1. 장면에 들어갈 것

- **구름 섬**: 몽글이가 사는 떠 있는 구름 섬. 레벨(1~5)마다 섬 크기·모양이 커진다(작은 구름 → 구름 언덕 → 구름 숲 → 큰 구름 섬 → 하늘 정원).
- **몽글이**: 섬 가운데. 지금 2D 몽글이와 같은 인상(구름 몸, 큰 눈, 머리 위 낙서 머리카락). 숨쉬듯 둥실거리는 기본 움직임.
- **식물 5종**: 일·공부=나무, 사람·관계=꽃, 쉼·몸=이끼, 좋아하는 것=열매, 생각·하루=버섯.
- **날씨**: 맑음·포근·흐림·비·천둥·바람 + 없음. 어떤 날씨도 정원에 좋은 일로 보이게(비 → 새싹, 천둥 → 뿌리).
- **계절**: 봄(꽃잎)·여름(반짝임)·가을(낙엽)·겨울(눈). 섬 풀빛도 계절마다 바뀐다.
- **꾸미기 아이템**(몽글이에게): 새싹 핀, 빨간 모자, 포근 목도리, 꽃 화관, 구름 왕관, 무지개 리본.

색은 지금 제품 색을 따른다. 기본 몽글이는 라벤더(`#B7A6FF`, 밝은 면 `#EEE8FF`)다.

## 2. 앱이 넣어 주는 변수

Spline의 Variables 패널에서 **아래 이름 그대로** 만든다. 이름이 다르면 무시된다. 값은 정원이 바뀔 때마다 다시 들어온다.

| 변수 | 종류 | 값 | 쓰임 |
|---|---|---|---|
| `level` | Number | 1~5 | 섬 크기·모양 |
| `plants` | Number | 0~ | 전체 식물 수 |
| `work` / `people` / `rest` / `likes` / `thoughts` | Number | 0~ | 주제별 식물 수(나무·꽃·이끼·열매·버섯을 몇 개 보일지) |
| `collected` | Number | 0~30 | 도감 칸 수(특별 연출용, 선택) |
| `weather` | String | `none` `sunny` `cozy` `cloudy` `rain` `thunder` `wind` | 날씨 연출 |
| `season` | String | `spring` `summer` `autumn` `winter` | 계절 연출 |
| `accessory` | String | `""` `sprout` `hat` `scarf` `flowers` `crown` `rainbow` | 몽글이 꾸미기 |

식물 수는 많아질 수 있다(1년이면 수백 개). 장면에는 주제마다 **최대 8개** 정도만 자리를 두고, `work >= 1`이면 나무 1번 보이기, `work >= 2`면 2번 보이기 식으로 State/Events의 조건을 건다.

## 3. 지켜야 할 것

- **시들거나 줄어드는 연출은 넣지 않는다.** 식물·섬은 커지기만 한다(쉬어도 시들지 않아요).
- **위기 표현이 있던 날의 날씨는 앱이 `none`으로 넣는다.** 날씨 연출로 그날을 꾸미지 않는다.
- 사람의 감정·성격을 드러내는 표정 변화(슬픈 몽글이 등)는 넣지 않는다.
- 동작 줄이기를 켠 사용자를 위해 큰 회전·흔들림은 피하고, 반복 움직임은 잔잔하게.
- 가볍게: 모바일 기준 장면 파일은 **3MB 이하**, 화면 비율은 **3:2**(가로 300 : 세로 200 기준), 배경은 하늘색 계열 단색이나 투명.

## 4. 내보내기와 연결

1. Spline에서 Export → **Code → Vanilla JS**(또는 React)를 고르고, 나온 `https://prod.spline.design/…/scene.splinecode` 주소를 복사한다.
2. 먼저 개발 화면에서 확인한다: `http://localhost:3000/dev/garden-preview?spline=<주소>`
   - `&level=1`~`5`로 레벨별 모습, `&accessory=hat`처럼 꾸미기를 바꿔 본다.
3. 확인이 끝나면 `.env.local`과 Vercel 환경변수에 `NEXT_PUBLIC_GARDEN_SPLINE_URL=<주소>`를 넣는다. 개발(Preview)에 먼저 넣고, 운영은 따로 승인받아 넣는다.

## 5. 앱 쪽 구현

- 연결 코드: `src/app/SplineGarden.tsx`(장면 불러오기·변수 넣기·실패 시 2D 그림), 변수 계산: `splineVariables()` in `src/lib/garden.ts`.
- Spline 런타임(`@splinetool/runtime` 2.0.95)은 정원이 화면에 나올 때만 따로 불러온다. 첫 화면 무게에는 들어가지 않는다.
- 런타임은 처리용 WASM 파일을 Spline CDN에서 받는다. 나중에 보안 정책(CSP)을 켜면 `prod.spline.design`과 런타임 CDN을 허용해야 한다.
- 정원 데이터는 여전히 이 기기에서만 계산한다. 변수는 브라우저 안의 장면에만 넣고, 앱 코드가 서버로 보내는 것은 없다. 장면 파일과 런타임 파일만 Spline 쪽에서 받는다.
