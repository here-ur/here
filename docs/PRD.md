## 3. MVP 기능

### 🎙️ 음성 대화

말하기 → 글로 바꾸기(STT) → AI 답변 → 목소리로 읽기(TTS)

- [x] **어떤 AI·음성 서비스를 쓸지** — 전부 OpenAI. 대화 `gpt-4.1-mini`, STT `gpt-4o-mini-transcribe`, TTS `gpt-4o-mini-tts`. 키는 서버(API 라우트)에만 둔다.
- [x] **대화를 어떻게 시작하고 끝낼지** — 시작 화면 "이야기 시작하기" → 시작 전 안내(AI라는 것, 기록은 이 기기에만, 109) → 몽글이 인사. "대화 마치기"를 누르면 시작 화면으로.
- [x] **소리 내기 어려울 때를 위해 글 입력도 둘지** — 둔다. 마이크를 못 쓰면 글 입력이 자동으로 열린다.

### 🏥 병원 연계

대화하다 필요하면 병원으로 이어 준다.

- [x] **어디까지 이어 줄지** — 병원 정보 + 전화·길 찾기(카카오맵)까지. 예약은 하지 않는다.
- [x] **언제 권할지** — AI가 대화 내용을 보고 권한다(어려움이 2주 넘게 이어지거나, 잠·식사·일상이 무너졌거나, 사용자가 전문가 도움을 원할 때). 권할 때도 "전문가와 이야기해 보는 것도 방법" 정도로만.
- [x] **병원 정보는 어디서 가져올지** — 공공데이터포털 "건강보험심사평가원_병원정보서비스". 내 위치 5km 안 정신건강의학과를 거리순으로만 보여 준다.

### 📒 내 기록 (MVP 예외로 추가)

- 몽글이 프로토타입 "내 기록"의 하루하루 탭만 옮겼다. 대화를 날짜별 카드로 보여 준다.
- 대화는 이 기기의 브라우저에만 30일 남고, 서버로 보내지 않는다.

## 5. 꼭 확인할 것

- 자살·자해 같은 위기 표현이 나오면 자살예방상담전화 **109**를 바로 안내한다. AI 답보다 먼저 띄운다.
- AI는 진단하지 않고, AI라는 걸 알린다.
- 병원 연결로 영리 목적의 환자 소개·알선을 하면 안 된다 (의료법 27조 3항). 병원에서 건당 수수료를 받는 구조는 피한다. 특정 병원을 추천·우선 노출하지 않는다.
