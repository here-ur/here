## 화면

- 홈 글 대화: 최신 30개 우선 표시
- 답변 대기 중에도 연속 전송 가능. 보낸 글은 즉시 개별 말풍선·임시 저장 큐에 기록
- 답변 요청은 순서대로 처리. 진행 중 추가한 메시지는 다음 요청에 묶어서 전달(요청당 최대 20개)
- 요청 실패 시 보낸 글 유지, ‘답변 다시 받기’ 또는 새 메시지 전송으로 재시도
- 입력창을 닫아도 진행 중인 답변과 대기 메시지 처리 유지
- 위쪽 끝에 도달한 뒤 다시 위로 스크롤/당기기 → 이전 30개 추가
- 버튼·키보드로도 이전 기록 접근 가능. 날짜 구분 표시
- 이전 기록 추가 시 읽던 위치 유지. 과거 기록을 읽는 동안 새 메시지가 와도 아래로 강제 이동하지 않음
- 라이브러리: 전체 대화 기록 메뉴·날짜 상세의 원문 펼치기 제거. 하늘·숫자 기능 유지

## 저장과 요약

- 글 대화: 서버에서 질문·생성 답변 저장 후 응답. 클라이언트의 계정별 임시 큐로 재시도 보완
- 음성: 완료된 사용자·캐릭터 자막을 모두 큐에 저장. 연결 종료 시 도착한 마지막 자막도 보존
- 입력 후 6초/다음 활동/온라인 복구/화면 떠남에서 전송. 실패한 원문은 계정별 로컬 큐에 두고 재시도
- 메시지 ID·배치 ID로 재전송 중복 방지. 같은 ID의 내용 변경 거절
- 대화를 구간별로 요약: 이번 구간의 양쪽 발언 + 직전 두 발언을 문맥으로 전달
- 새 사실은 이번 구간에서만 추출. 캐릭터의 제안·검색 답변을 사용자 사실로 바꾸지 않도록 화자 구분
- 인사·단순 질문도 대화 주제로 요약. 비밀번호·인증번호·연락처 등 제외
- 요약 모델: `openai/gpt-5.6-luna`, 임베딩: `text-embedding-3-large` 1536차원
- 미완료 요약 작업은 DB에 남음. 다음 기록 저장/조회에서 실패·중단 작업 재시도. 사용자가 장기간 접속하지 않을 때도 실행되는 별도 요약 작업자는 아직 없음
