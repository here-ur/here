# 대화 뒤 작은 실천·요일 체크 (시안, 팀 확인 전)

홈·구름 정원(예전 인사이트)에 "다시 돌아올 이유"를 만드는 두 가지 시안이다. **디자인 시안만 있고 실제 홈·구름 정원(예전 인사이트)에는 연결하지 않았다.** 데이터·API 연결도 없다. 확인용 화면은 `http://localhost:3000/dev/practice-preview`(개발에서만 열림)이고, 위의 장면 버튼으로 홈 기본 → 대화 뒤 → 위기 뒤 → 구름 정원를 바꿔 본다.

참고한 것: Tolan 홈의 Intentions 카드(넘겨 보기·남은 개수 배지·완료 체크), Ahead의 5분 기법·요일 체크·완료 수. 사람을 규정하는 레벨 이름("anger guru")과 스트릭·불꽃은 가져오지 않았다.

## 1. 대화 뒤 작은 실천 제안

- **대화 뒤 카드**(`PracticeCard`): 글·음성 대화를 마치고 기본 홈으로 돌아왔을 때 하단 버튼 위에 한 장. "몽글이와 이야기한 뒤 해 볼 만한 작은 것" → 제목 → "N분 · 안 해도 괜찮아요". 버튼은 **해 볼게요 / 나중에 / 닫기(×)**.
  - 해 볼게요 → 시트(`PracticeSheet`): 단계 2~3줄, 숨 고르기는 원이 4초/6초로 숨 쉼(동작 줄이기에서는 멈추고 글로만), **다 했어요 / 다음에 할게요**. 다 했어요를 누르면 체크가 남고 몽글이가 한 번 튄다.
  - 나중에 → 그 제안을 오늘 목록 뒤로 보내고 다음 것을 보여 준다. 닫기 → 오늘은 그 제안을 다시 보여 주지 않는다. 하나를 하고 나면 바로 다음 카드를 들이밀지 않는다.
- **홈 기본 상태의 작은 형태**(`PracticeMini`): 헤더 아래 "오늘 해 볼 만한 것" 한 줄과 옆으로 넘기는 카드 3장. 오른쪽에 "N개 남음" 배지, 한 것은 체크·취소선. 누르면 같은 시트가 열린다.
- **위기 뒤**: 위기 표현이 있던 대화 뒤에는 카드·작은 형태를 모두 감추고 기존 109 안내만 보여 준다(`notice`가 있으면 `spotlight`를 그리지 않는다).

### 지킨 것

- 제안은 **대화 내용으로 고르지 않는다.** `dailyPractices(date)`가 정해진 목록을 날짜 번호로 돌려 하루 3개를 정하고, 사용자가 그중에서 고른다. "불안해 보여요" 같은 추측 문구는 없다.
- 문구는 "해 볼 만한 작은 것 · 안 해도 괜찮아요"까지만. 진단·처방·권고처럼 읽히는 말은 쓰지 않는다. 사람을 규정하는 레벨 이름·프로필 문구는 없다.
- 기록(한 것·나중에·닫은 것)은 계정별로 이 기기 `localStorage`(`here.practice.v1`, 1년)에만 두고 서버·AI에 보내지 않는다. 시트에서 떠올린 내용은 어디에도 저장하지 않는다.
- 컬러·캐릭터는 기존 그대로, 타이포·간격·라운드·모션은 SEED 토큰(`text-t*`, `rounded-r*`, `ui-press`, `animate-rise/screen-in`)을 쓴다. 동작 줄이기에서는 숨 고르기 원·카드 등장·몽글이 반응이 멈춘다.

## 2. 가벼운 게임 요소

- **이번 주 요일 체크**(`WeekChecks`): 월~일 7칸, 글·아이콘 없이 색으로만. 이야기한 날은 몽글이 색으로 연하게, 실천한 날은 진하게 칠하고 오늘은 테두리. 쉰 날·아직 안 온 날은 빈 원이고 ×나 "0일" 같은 실패 표시·설명 문구는 없다. 오른쪽에 불꽃 아이콘과 **쌓인 실천 수**(누적, 줄지 않음. 스트릭이 아니라서 꺼지지 않는다).
- **몽글이 반응**: 체크하면 몽글이가 한 번 '통' 튄다. 새 동작을 만들지 않고 기존 연결 동작 중 생각→말하기의 `pop`을 다시 쓴다(`Buddy`의 `cheer` 값이 바뀔 때 한 번). 표정은 바꾸지 않는다.
- 시안에서는 구름 정원 화면 맨 위(섬 위)에 두었다. 제안 카드는 홈에만 두고 이 화면에는 넣지 않는다. 홈에도 둘지는 아래 결정 사항이다.

## 3. 팀이 정해야 할 것 (모두 임시값)

| 항목 | 지금 시안의 임시값 | 정할 것 |
|---|---|---|
| 제안 목록·문구 | 8개: 1분 숨 고르기, 오늘 좋았던 것 한 줄, 물 한 컵 마시기, 어깨 세 바퀴 돌리기, 창밖 1분 바라보기, 고마운 사람 한 명 떠올리기, 내일 할 일 하나만 정하기, 집 안 한 바퀴 걷기 | 최종 목록, 단계 문구, 소요 시간. 의료·치료 기법처럼 들리는 이름은 피할지(예: "호흡법" 대신 "숨 고르기") |
| 고르는 방식 | 날짜 번호로 돌려 하루 3개 | 돌리기 유지 / 사용자가 관심 주제를 미리 고름 / 둘 다. 대화 내용으로는 고르지 않는다는 원칙은 유지 |
| 보여 주는 시점 | 대화를 마치고 기본 홈으로 돌아온 직후 한 장, 홈 기본 상태에는 작은 형태 상시 | 매 대화 뒤인지 하루 한 번인지, 몇 마디 이상 나눈 대화에만인지, 음성과 글을 같게 볼지 |
| 하루 개수·다시 보기 | 하루 3개, 닫으면 그날은 안 보임, 나중에는 뒤로 | 개수, 닫은 제안을 다음 날 다시 보여 줄지 |
| 스트릭 기준 | 스트릭 없음. 요일 체크는 대화한 날과 실천한 날을 따로 표시, 누적 실천 수만 셈 | 연속 일수를 아예 두지 않을지, 둔다면 대화 기준인지 실천 기준인지, 끊겨도 잃는 느낌이 없게 어떻게 보여 줄지 |
| 보상 형태 | 몽글이가 한 번 튀는 반응, 누적 실천 수 | 구름 정원과 연결할지(실천한 날 씨앗·꾸미기 아이템 등), 효과음·햅틱, 몽글이 반응 추가 여부 |
| 위치 | 요일 체크·누적 수는 구름 정원 맨 위, 제안은 홈 | 홈에도 요일 체크를 둘지 |
| 불꽃 아이콘 | 누적 실천 수 옆에 불꽃(Ahead 참고) | 불꽃이 스트릭처럼 읽히지 않는지, 다른 아이콘(새싹 등)으로 바꿀지 |
| 위기 뒤 처리 | 카드·작은 형태 모두 감추고 109만 | 그날 하루 동안 감출지, 그 대화 뒤만 감출지 |
| 데이터 보관 | 이 기기 `localStorage`, 계정별, 1년 | 보관 기간, "기록 모두 지우기"에 포함할지(포함 예정), 기기 바꾸면 사라져도 되는지 |
| 완료 확인 | "다 했어요" 버튼으로 사용자가 스스로 체크 | 타이머·입력 없이 자기 보고로 둘지 |
| 법무·문구 확인 | 미확인 | 건강 조언으로 읽히지 않는지, 호흡·운동 안내에 주의 문구가 필요한지 |

## 4. 코드 위치

- 데이터·규칙: `src/lib/practice.ts`(목록, 날짜 돌리기, 기기 기록, 요일 체크, 누적 수), 테스트 `src/lib/practice.test.ts`
- 화면: `src/app/Practice.tsx`(`PracticeMini`, `PracticeCard`, `PracticeSheet`, `WeekChecks`), `src/app/practice.css`
- 홈에 꽂는 자리: `HomeScreen`의 `spotlight`(위쪽 작은 형태)·`nudge`(하단 카드) 슬롯. 기본 홈에서만 보이고 대화 중·위기 안내가 있을 때는 감춘다. 실제 `page.tsx`에는 아직 연결하지 않았다.
- 몽글이 반응: `Buddy`의 `cheer` 값(기존 `pop` 동작 재사용)
- 미리보기: `src/app/dev/practice-preview/`
